# 数据与标注规范 v1

## 采集
- 自然光或色温 5000–6500K 的稳定光源,避免逆光/强闪光;建议每张照片带标准灰卡/色卡
- 舌自然伸出、放松,不过度用力;拍摄距离 15–25cm,舌体占画面 ≥ 30%
- 避开染苔因素(咖啡、茶、饮料、药物、刚刷舌);记录进食后时间
- 记录:设备型号、光源、拍摄时间;**必须有知情同意书**

## 标注 CSV 列
| 列 | 说明 |
|---|---|
| view | **舌面**(伸舌看舌背)/ **舌下**(卷舌看舌下络脉)/ 拼图 / 其他。本引擎当前只支持「舌面」,其他类型需分流 |
| image_path | 相对 --root 的路径(预处理后的裁剪图) |
| patient_id | **必填**,用于按人划分数据集,防泄漏 |
| tongue_color | 淡白/淡红/红/绛/紫暗 |
| tongue_size | 胖大/正常/瘦薄 |
| coating_color | 无苔/白/黄/灰黑 |
| coating_thickness | 少/无、薄、厚 |
| coating_moisture | 润/滑/燥 |
| coating_greasy | 无/腻/腐 |
| teeth_marks / cracks / prickles | 1/0,未标注留空 |

## 标注质量
- 至少 2 名有资质的中医师独立标注,分歧由第 3 位仲裁;报告 Cohen's κ
- 标注手册需附参考图例;定期抽检
- 建议同时记录体质量表(9 种体质,ZYYXH/T157-2009)得分,用于校准 constitution.py 中的先验权重

## 真实场景数据的注意事项(来自首批 41 张客户照片的复盘)
- 多为手机自拍/微信转发:光线、背景、色温差异大,**同一舌象在不同光源下舌色判读会偏移**,必须记录设备/光源,并尽量带灰卡
- 大约一半是舌下照片、少量是多图拼图,须先分流(`view` 列),不能混入舌面训练集
- 画面含人脸:裁剪后只保留舌体区域即可去标识;原图必须受控存放,不得进入仓库
- 微信压缩图(<100KB、<720px)细节(裂纹、点刺、苔质)已丢失,不建议用于训练这些标签
- 同一客户多次拍摄(如 5月12日/6月1日对比拼图)需用同一 patient_id,否则会数据泄漏
